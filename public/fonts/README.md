# PDF fontları

Noto Sans Regular ve Bold statik TTF dosyaları, resmi `notofonts/noto-fonts`
deposunun `hinted/ttf/NotoSans` dizininden alındı (2026-09-26).
Kaynak: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans

SIL Open Font License 1.1 metni `OFL.txt` içinde korunmuştur. Türkçe/Latin
Extended kapsamı; PDF içinde gömülü metin fontu. Runtime ağ isteği yoktur.
React PDF fonts dokümantasyonundaki TTF desteği ve ayrı 400/700 ağırlıklar
kullanılır; variable font kullanılmaz. Next PDF route tracing TTF'leri kapsar.
